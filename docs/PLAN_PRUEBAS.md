# Plan de pruebas - ShopApp

## Android

| ID | Prueba | Resultado esperado |
|---|---|---|
| AND-01 | Inicio de sesión | Se accede al catálogo |
| AND-02 | Carga de productos | Los productos llegan desde la API |
| AND-03 | Crear producto | El producto aparece en el catálogo |
| AND-04 | Editar producto | Los cambios se reflejan |
| AND-05 | Eliminar producto | El producto desaparece |
| AND-06 | Agregar al carrito | Aumenta el contador |
| AND-07 | Cambiar cantidad | El subtotal cambia |
| AND-08 | Persistencia local | El carrito permanece tras recargar |
| AND-09 | Cerrar sesión | Se regresa al acceso |

## iOS

Repetir las mismas pruebas en simulador o dispositivo iOS cuando se disponga de macOS/Xcode.

**Importante:** no declarar una prueba como ejecutada hasta contar con la evidencia correspondiente.
